# Vesper / Nocturne

بازسازی مستقل و قابل ویرایش از تجربهٔ بصری Vesper در Scrolltide.

## اجرا

Node.js 20.19 یا جدیدتر لازم است.

```powershell
npm install
npm run dev
```

آدرس توسعه: `http://127.0.0.1:4178`

```powershell
npm run build
npm run preview
node scripts/verify.mjs
npm run models
```

## پیاده‌سازی

- Vite، JavaScript، Three.js و GSAP؛ فایل‌های مستقل و بدون سرویس تصویر خارجی.
- بطری سه‌بعدی با هندسهٔ چرخشی، نور استودیویی با بازتاب باریک، لیبل کاغذی و کپسول فلزی با لبهٔ گرد؛ حرکت هنگام اسکرول و جای‌گیری در بخش محصولات.
- بافت کاغذ، فرسودگی حروف، مهر، لکه‌ها و رد لیوان با SVG.
- عکس‌های اختصاصی تولیدشده با ابزار داخلی ImageGen؛ اصل PNG در `design/assets` و WebP در `public/assets`.
- شش مدل GLB در `public/models` و هندسه و متریال‌های قابل ویرایش در `src/models.js`. رندر جعبه‌ها بافت چوب و مهر دارد؛ GLB جعبه‌ها متریال پایه دارد.
- تصاویر کاتالوگ از همین مدل‌ها رندر شده‌اند. برای بازتولید در محیط توسعه، `/?render-products=1` را باز کنید؛ رندرهای شفاف ۱۲۹۶ × ۱۵۱۲ پیکسل در عناصر تصویر صفحه قابل ذخیره‌اند. `scripts/optimize-cutouts.py` با Pillow، PNGها را به WebP تبدیل می‌کند و اصل‌ها را حفظ می‌کند.
- منو، جست‌وجوی فصل‌ها، اطلاعات تکمیلی، انتخاب محصول، فرم رزرو و خبرنامه پیاده شده‌اند.
- چینش موبایل و تبلت، صفحه‌کلید، دیالوگ بومی، وضعیت فرم‌ها و کاهش حرکت در نظر گرفته شده است. در نبود WebGL، تصویر همان بطری بازسازی‌شده جایگزین می‌شود و تصاویر محصول حفظ می‌شوند.
- فونت‌ها محلی هستند؛ مجوزهای OFL در `public/fonts/licenses` قرار دارند.

## مرز تطابق با نمونه

ترکیب‌بندی، ترتیب فصل‌ها، رنگ‌ها و الگوی حرکت از نمونه بازسازی شده‌اند. عکس‌ها، فونت‌های جایگزین و مدل‌ها اختصاصی این پروژه‌اند؛ تطابق پیکسل‌به‌پیکسل با فایل‌های اصلی نمونه ادعا نمی‌شود. فیلم اصلی در دسترس نیست؛ دکمهٔ معرفی سازنده، دیالوگ تصویری و روایت را باز می‌کند. پرداخت، سفارش واقعی، ایمیل و پنل مدیریت به بک‌اند متصل نشده‌اند. اطلاعات فرم‌ها فقط در مرورگر ذخیره می‌شوند. جزئیات محصول و شخصیت‌ها نمایشی‌اند.
